# 个人健康助手：记忆与问答

你有完整两小时，基于给定历史对话实现一个可复现的记忆问答系统：**构建可复用记忆，召回与新问题有关的内容，并给出有原文依据的具体回答。** 只返回记忆列表不算完成答题。

同一账号的对话涉及本人、家人和一般讨论，信息会补充、变化或澄清。请让答案忠实于对应观察点内的记录；信息不足时说明已经知道什么、缺少什么。健康内容仅作对话事实处理，不要求临床诊断或新的诊疗建议，也不能用外部医学知识补全个人经历。

## 给你的材料

- `data/initial.jsonl`：10段完整会话，140条消息。
- `data/incremental.jsonl`：后续6段完整会话，88条消息。
- `questions.jsonl`：6道公开问题，只有题号、问题、观察点，没有答案或回答要点。面试官另有9道未公开问题。
- `INTERFACE.md`：用于自动验收的输入输出格式。

每行JSONL为一个完整会话。`sequence` 是接收顺序；`as_of_sequence=N` 表示回答只能依据第1至N段中已知的信息。`recorded_at=null` 表示没有可靠会话日期，正文事件时间不能自动当成记录时间。账号ID不等于正文中所有人的主体。

## 工作范围

自行选择实现语言、记忆表示、检索方法和是否使用模型。构建应独立于具体问题，支持由初始数据构建、追加增量、保存并恢复记忆；查询应实际使用已构建记忆，支持旧观察点。避免把全部历史在每个问题中重新交给模型。无需前端框架、部署、服务端账户或复杂基础设施。

问题的答案、召回的记忆及其证据要一起返回。检索结果不必凑满；少召回可能遗漏关键事实，过多无关内容也会影响评价。公开题和隐藏题使用同一接口、同一份记忆与代码，不应硬编码题目答案。

两小时结束一次性交付，提交后统一验收。自行决定是否使用AI工具；不设中途检查、现场演示或答辩。AI使用复盘是提交材料的一部分，不要求完整聊天、提示词、录像或开发轨迹。

## 交付物

1. **可复现、可验证的记忆构建代码**：源码、依赖配置、统一入口 `run.sh`、简要 `README.md`、可运行测试及实际结果。面试官应能从原始数据重建、查询和导出。模型服务及环境变量按真实情况说明。
2. **排查展示 `report.html`**：本地直接打开，展示构建后的记忆、每道公开题的检索/排查记录、关键原文证据与具体结论。由候选人自行实现，不提供生成工具，不评价页面美观。排查记录是可观察的检索步骤和证据，不要求模型隐式思维链。
3. **逐题回答 `answers.jsonl`**：对6道公开题实际运行查询，每行保存题号、原问题、观察点和完整真实返回值，与HTML一致；格式见接口文件。不能手写预期结果冒充运行结果。
4. **AI工具使用复盘 `AI_NOTES.md`**：记录实际使用方式、踩坑、解决办法、验证结果和可复用经验。未使用AI也提交此文件，如实说明未使用，以及自己的排查与验证经验；不因未使用AI扣分。不要填入密钥。

统一入口：

```bash
./run.sh ingest --input data/initial.jsonl --store ./store
./run.sh ingest --input data/incremental.jsonl --store ./store
./run.sh query --store ./store --query "问题" --as-of-sequence 10 --top-k 8
./run.sh export --store ./store
```

HTML需要的两段JSON嵌入约定见接口文件。页面可保持简单，重点是实际构建产物、检索记录、证据和答案能够核对。

## 如何评价

隐藏题用于主要效果评分，公开题用于交付自测和一致性核验。总分100分，只看最终效果与交付：**回答质量60分、召回质量25分、整体交付与可复现15分**，不按开发环节、框架或组件逐项分配分数。

- 回答：是否真正回答问题，事实、主体、状态、时间、信息边界是否正确，证据能否核验。
- 召回：关键事实是否遗漏，无关、重复或错误记忆是否过多。人工判断语义，再汇总覆盖率、漏召回率、相关性精度及F1；参考来源ID不是唯一正确答案。
- 交付：能否重建并验证，HTML、真实逐题输出和复盘是否完整一致，测试与说明是否可信。

同时报告构建输入/生成输出token、倍率，以及检索耗时和整次查询耗时。**token与耗时不直接加扣分，也不设质量准入门槛。** 耗时会展示样本数、成功/失败情况及分位数，供面试官了解表现。构建耗时不评分。

查询最多8条记忆；记忆正文与引文合计不超过2,400个Unicode字符；具体回答另限1,200字符。查询中所有模型调用发送的历史内容累计不超过6,000字符。以Python `len(str)`计数，重复发送重复计算。固定指令和当前问题不计入历史预算。接口和计量规则见 `INTERFACE.md`。

数据许可与署名见 `LICENSE_NOTICE.md`。题面不提供答案库、标注文件或评分参考答案。
